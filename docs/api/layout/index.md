# 布局实例

布局实例是图的布局控制器，负责执行具体的布局算法并管理布局的启动、迭代与停止。通过 [`getLayout`](#getlayout) 获取当前图的布局实例。

## 属性

### id

- **类型**：`string`
- **描述**：布局类的 ID。

### isStop

- **类型**：`boolean`
- **描述**：是否停止布局，用于控制布局的开始与结束。

## 方法

### 生命周期

#### execute

- **参数**：`options: LayoutOptions`
- **返回值**：layout 实例
- **描述**：布局开始执行的入口方法。

#### stop

- **参数**：无
- **返回值**：无
- **描述**：结束布局，供迭代布局调用。

#### restart

- **参数**：无
- **返回值**：无
- **描述**：重新启动布局。

### 执行

#### layout

- **参数**：无
- **返回值**：无
- **描述**：执行布局的具体方法。

#### tick

- **参数**：`iterations: number`
- **返回值**：无
- **描述**：迭代布局中执行的方法。`iterations` 表示预先迭代的次数，默认为一次。

#### ticker

- **参数**：`ticker: Ticker`
- **返回值**：无
- **描述**：外部 `Application.ticker` 每一帧执行一次。这里使用 [`isStop`](#isstop) 来控制何时结束执行、何时开始执行。
