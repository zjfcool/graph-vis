Link Options (LinkOptions) ​

LinkOptions is used to configure the style of the dynamic link that follows the mouse cursor when performing edge editing operations on the graph. It is typically passed as the link property of GraphVisOptions.

LinkOptions inherits the type, style, state, arrowConfig, and labelConfig options from EdgeOptions by default. If link is configured separately, those configurations will be overridden.

ts
type LinkOptions<D = any> = Omit<EdgeOptions<D>, "source" | "target" | "drawBy" | "id">;

Compared with EdgeOptions, LinkOptions removes four properties: source, target, drawBy, and id. This is because the dynamic link is generated by user interaction, its source and target nodes are not fixed, and its drawing method is fixed to graphics.

1. Options Quick Reference ​

2. Key Options ​

2.1 Edge Type (type) ​

LinkOptions inherits the type property from EdgeOptions, used to specify the type of the dynamic link.

Built-in edge types:

  • auto: Adaptive; automatically selects the appropriate type based on the edge's connection relationship
  • line: Straight line
  • quadratic: Quadratic Bezier curve
  • cubic: Cubic Bezier curve
js
link: {
  type: 'line',
}

2.2 Style (style) ​

Controls the stroke, halo, curve shape, etc. of the dynamic link. See LinkStyleOptions below for details.

js
link: {
  style: {
    stroke: {
      width: 3,
      color: '#000',
    },
  },
}

2.3 Arrow Configuration (arrowConfig) ​

Controls the visibility, position, size, and style of the arrow on the dynamic link.

js
link: {
  arrowConfig: {
    style: {
      visible: true,
      size: [8, 6],
    },
  },
}

2.4 Label Configuration (labelConfig) ​

Controls the text, position, and style of the dynamic link's label.

js
link: {
  labelConfig: {
    labelText: () => 'New Link',
    style: {
      visible: true,
      fontSize: 12,
    },
  },
}

2.5 State (state) ​

You can define different states for the dynamic link. By default, it inherits the state options from EdgeOptions.

js
link: {
  state: {
    active: { halo: true, haloSpacing: 3 },
  },
}

3. Link Style Options (LinkStyleOptions) ​

4. Complete Example ​

The following example shows how to configure the style of the dynamic link:

js
import { GraphVis } from "@zjfcool/graph-vis";

new GraphVis({
  // ... other options
  link: {
    type: "line",
    style: {
      stroke: {
        width: 3,
        color: "#000",
      },
    },
    arrowConfig: {
      style: {
        visible: true,
        size: [8, 6],
      },
    },
    labelConfig: {
      labelText: () => "New Link",
      style: {
        visible: true,
        fontSize: 12,
      },
    },
  },
});

5. Notes ​

  1. Inheritance: LinkOptions inherits from EdgeOptions. If a property is not configured in link, the corresponding configuration in edge is used.
  2. Non-configurable properties: The four properties source, target, drawBy, and id cannot be configured in LinkOptions.
  3. Fixed drawing method: The drawing method of the dynamic link is fixed to graphics, so only graphics-related properties take effect.
  4. Interaction trigger: The dynamic link starts to appear after calling the startLinkNode method, and disappears after calling the endLinkNode method.
  5. Dynamic generation via functions: Consistent with EdgeOptions, most properties in LinkOptions support passing a function, where the function parameter d is the raw edge data.

With the options above, you can flexibly control the appearance, arrow, label, and interaction state of the dynamic link.
