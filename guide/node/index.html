节点配置 (NodeOptions) ​

NodeOptions 用于配置图中节点的类型、绘制方式、状态、文本、样式和标签等。它通常作为 GraphVisOptions 的 node 属性传入。其配置项支持静态值和函数动态生成两种形式，函数参数 d 为节点的原始数据。

1. 配置项速查表 ​

属性类型默认值描述
typeAttrType<NodeType>circle节点类型，内置 circle、ellipse、image、polygon、rect、text、bitmap-text、star 等
drawByAttrType<DrawBy>graphics绘制方式，graphics 或 sprite
stateNodeStateOptions-节点状态配置项，如 active、selected、inactive
textValueAttrType<TextType>-当节点类型为 text 或 bitmap-text 时生效，返回文本内容
styleNodeStyleOptions-节点样式配置项
labelConfigNodeLabelConfigOptions-节点标签配置项

2. 重点配置说明 ​

2.1 节点类型 (type) ​

内置节点类型：

  • circle：圆形
  • ellipse：椭圆
  • rect：矩形（支持圆角）
  • polygon：多边形
  • star：多角星
  • image：图片
  • text：文本
  • bitmap-text：位图文本

类型定义为 NodeType，支持通过函数根据数据动态返回类型：

js
type: (d) => (d.category === "person" ? "circle" : "rect");

2.2 绘制方式 (drawBy) ​

绘制方式类型为 DrawBy：

  • graphics：使用 PixiJS Graphics 绘制（默认）
  • sprite：使用 Sprite 绘制

部分样式属性仅在特定绘制方式下生效，详见 NodeStyleOptions 表格中的 drawBy 列。

2.3 状态 (state) ​

可以为节点定义不同的状态，每个状态可以覆盖 style 和 labelConfig 中的样式。默认包含 active、selected、inactive 三个状态，你也可以自行添加。

js
state: {
  active: { halo: true, haloSpacing: 3 },
  selected: { halo: true, haloSpacing: 3 },
  inactive: { halo: false },
}

详细配置见 NodeStateOptions。

2.4 文本值 (textValue) ​

仅当 type 为 text 或 bitmap-text 时生效，用于返回要渲染的文本内容。类型为 TextType，可以是字符串、数字或任何实现了 toString 方法的对象。

js
textValue: (d) => d.label;

2.5 样式 (style) ​

控制节点的填充、描边、光晕、尺寸等，详见下方 NodeStyleOptions。

2.6 标签配置 (labelConfig) ​

控制节点标签的文本、位置、样式等，详见下方 NodeLabelConfigOptions。

5. 节点状态配置项 (NodeStateOptions) ​

默认包含 active、selected、inactive 三个状态，你可以自行添加更多状态。

属性类型默认值描述

节点状态样式配置项 (NodeStateStyleOptions) ​

NodeStateStyleOptions 继承 NodeStyleOptions，并扩展以下属性：

属性类型默认值描述
labelStyleNodeLabelStyleOptions-该状态下节点标签的样式配置项

6. 完整示例 ​

以下示例展示了节点动态样式、状态配置和标签配置：

js
import { GraphVis } from "@zjfcool/graph-vis";

new GraphVis({
  // ... 其他配置
  node: {
    type: "circle",
    state: {
      active: {
        halo: true,
        haloSpacing: 3,
      },
      selected: {
        halo: true,
        haloSpacing: 3,
      },
      inactive: {
        halo: false,
      },
    },
    style: {
      visible: true,
      size: (d) => d.weight * 5 + 10,
      pointNum: 5,
      rotation: 0,
      radius: 0,
      haloRadius: 0,
      halo: false,
      haloSpacing: 3,
      alpha: 1,
      haloAlpha: 0.55,
      fill: (d) => (d.category === "important" ? "#ff4d4f" : "#409eff"),
    },
    labelConfig: {
      labelText: (d) => d.label,
      style: {
        visible: true,
        placement: (d) => (d.id % 2 === 0 ? "right" : "left"),
        offsetX: 0,
        offsetY: 0,
        fontSize: 12,
        halo: false,
        haloSpacing: 0,
        haloRadius: 2,
        haloAlpha: 0.55,
      },
    },
  },
});

7. 注意事项 ​

  1. 函数动态生成：NodeOptions 中的大部分属性都支持传入函数，函数参数 d 为节点的原始数据。这使得你可以根据数据动态决定节点样式。
  2. drawBy 的影响：graphics 和 sprite 两种绘制方式支持的样式属性不同，请参考表格中的 drawBy 列。
  3. 状态优先级：当节点处于某个状态时，该状态下的样式会覆盖基础样式。如果状态中未定义的属性，会继续使用基础样式。
  4. 文本节点：当 type 为 text 或 bitmap-text 时，textValue 用于设置文本内容，同时 style 中可以使用 TextStyleOptions 的所有属性。
  5. 标签配置：labelConfig.labelText 默认取 d.label，你可以根据数据自定义。

通过以上配置，你可以灵活地控制节点的外观、标签和交互状态。
