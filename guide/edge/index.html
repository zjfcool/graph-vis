边配置 (EdgeOptions) ​

EdgeOptions 用于配置图中边的类型、绘制方式、状态、样式、箭头和标签等。它通常作为 GraphVisOptions 的 edge 属性传入。其配置项支持静态值和函数动态生成两种形式，函数参数 d 为边的原始数据。

1. 配置项速查表 ​

属性类型默认值描述
typeAttrType<string>auto边类型，内置 auto、line、quadratic、cubic 四种
idstringid边 ID 对应的 key
sourcestringsource边 source 对应的 key
targetstringtarget边 target 对应的 key
drawByAttrType<DrawBy>graphics绘制方式，graphics 或 sprite

labelConfigEdgeLabelConfigOptions-边标签配置项

更多属性请参考 EdgeOptions 详细文档。

2. 重点配置说明 ​

2.1 边类型 (type) ​

内置边类型：

  • auto：自适应，根据边的连接关系自动选择合适的类型
  • line：直线
  • quadratic：二次贝塞尔曲线
  • cubic：三次贝塞尔曲线

支持通过函数根据数据动态返回类型：

js
type: (d) => (d.weight > 5 ? "cubic" : "line");

2.2 绘制方式 (drawBy) ​

绘制方式类型为 DrawBy：

  • graphics：使用 PixiJS Graphics 绘制（默认）
  • sprite：使用 Sprite 绘制

部分样式属性仅在特定绘制方式下生效，详见 EdgeStyleOptions 表格中的 drawBy 列。

2.3 数据字段映射 (id / source / target) ​

用于指定边数据中哪个字段对应边的 ID、源节点 ID 和目标节点 ID。默认使用 id、source、target，如果你的数据字段名不同，可以自定义：

js
edge: {
  id: 'edgeId',
  source: 'from',
  target: 'to',
}

2.4 状态 (state) ​

可以为边定义不同的状态，每个状态可以覆盖 style、arrowConfig 和 labelConfig 中的样式。默认包含 active、selected、inactive 三个状态，你也可以自行添加。

js
state: {
  active: { halo: true, haloSpacing: 3 },
  selected: { halo: true, width: 2 },
  inactive: { halo: false },
}

详细配置见 EdgeStateOptions。

2.5 样式 (style) ​

控制边的描边、光晕、曲线形状等，详见下方 EdgeStyleOptions。

2.6 箭头配置 (arrowConfig) ​

控制边箭头的显示、位置、尺寸和样式，详见下方 EdgeArrowConfigOptions。

2.7 标签配置 (labelConfig) ​

控制边标签的文本、位置、样式等，详见下方 EdgeLabelConfigOptions。

6. 边状态配置项 (EdgeStateOptions) ​

边状态默认有 active、selected、inactive 三个配置项，key 的类型为 string。你可以自行添加更多的边状态配置项。

属性类型默认值描述

边状态样式配置项 (EdgeStateStyleOptions) ​

EdgeStateStyleOptions 继承 EdgeStyleOptions，并扩展以下属性：

属性类型默认值描述

7. 完整示例 ​

以下示例展示了边动态样式、状态配置、箭头配置和标签配置：

js
import { GraphVis } from "@zjfcool/graph-vis";

new GraphVis({
  // ... 其他配置
  edge: {
    type: "auto",
    state: {
      active: {
        halo: true,
        haloSpacing: 3,
        haloAlpha: 0.55,
      },
      selected: {
        stroke: {
          width: (d) => (d.id > 100 ? 2 : 1),
        },
        halo: true,
        width: 2,
        haloSpacing: 3,
        haloAlpha: 0.55,
      },
      inactive: {
        halo: false,
      },
    },
    style: {
      visible: (d) => d.id % 2 === 0,
      smoothness: 0.75,
      halo: false,
      haloSpacing: 3,
      alpha: 1,
      stroke: {
        width: 1,
        color: (d) => (d.weight > 5 ? "#ff4d4f" : "#c0c4cc"),
      },
      width: 1,
    },
    arrowConfig: {
      style: {
        visible: true,
        size: [6, 4],
        tailMidpointRatio: 0.2,
        alongT: 1,
      },
    },
    labelConfig: {
      labelText: (d) => d.label,
      style: {
        visible: true,
        alongT: (d) => 0.5,
        alongTPositionMode: "local",
        offsetPositionMode: "local",
        offsetX: 0,
        offsetY: 0,
        fontSize: 12,
        halo: false,
        haloSpacing: 0,
        haloRadius: 2,
        haloAlpha: 0.55,
      },
    },
  },
});

8. 注意事项 ​

  1. 函数动态生成：EdgeOptions 中的大部分属性都支持传入函数，函数参数 d 为边的原始数据。这使得你可以根据数据动态决定边样式。
  2. drawBy 的影响：graphics 和 sprite 两种绘制方式支持的样式属性不同，请参考表格中的 drawBy 列。
  3. 边类型的选择：auto 会根据连接关系自动选择，若需要精确控制曲线形状，建议显式指定 line、quadratic 或 cubic。
  4. 状态优先级：当边处于某个状态时，该状态下的样式会覆盖基础样式。如果状态中未定义的属性，会继续使用基础样式。
  5. 箭头配置：arrowConfig.style.alongT 控制箭头在边上的位置，tailMidpointRatio 影响箭头的形状。
  6. 标签配置：labelConfig.labelText 默认取 d.label，alongT 控制标签在边上的位置，alongTPositionMode 和 offsetPositionMode 控制坐标系。

通过以上配置，你可以灵活地控制边的外观、箭头、标签和交互状态。
