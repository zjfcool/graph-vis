图实例 ​

图实例graph对象上的属性与方法说明

js
import { GraphVis } from "@zjfcool/graph-vis";
const graph = new GraphVis({
    ...
})

属性 ​

type ​

  • 类型：GraphologyType
  • 描述：图的类型，可为有向、无向或混合。

order ​

  • 类型：number
  • 描述：图中节点的总数量。

size ​

  • 类型：number
  • 描述：图中边的总数量。

multi ​

  • 类型：boolean
  • 描述：图是否为多边模式。

allowSelfLoops ​

  • 类型：boolean
  • 描述：图是否允许自循环边。

directedSize ​

  • 类型：number
  • 描述：图中有向边的总数量。

undirectedSize ​

  • 类型：number
  • 描述：图中无向边的总数量。

selfLoopCount ​

  • 类型：number
  • 描述：图中自循环边的数量。

directedSelfLoopCount ​

  • 类型：number
  • 描述：图中有向自循环边的数量。

undirectedSelfLoopCount ​

  • 类型：number
  • 描述：图中无向自循环边的数量。

canvas ​

  • 类型：HTMLCanvasElement
  • 描述：canvas 元素。

screenCenterX ​

  • 类型：number
  • 描述：屏幕中心点的 x 坐标。

screenCenterY ​

  • 类型：number
  • 描述：屏幕中心点的 y 坐标。

transform ​

  • 类型：ZoomTransform
  • 描述：返回 ZoomTransform 实例对象。详情参见 d3-zoom#zoomTransform。

implementation ​

  • 类型：string
  • 描述：图实现的名称。

方法 ​

生命周期与清理 ​

init ​

  • 参数：无
  • 返回值：Promise
  • 描述：图初始化的方法。

destroy ​

  • 参数：无
  • 返回值：无
  • 描述：销毁图实例，之后不可再使用。

clear ​

  • 参数：无
  • 返回值：GraphVis 实例
  • 描述：清空图所有的节点与边，并同步清理画布上对应的图形。

clearEdges ​

  • 参数：无
  • 返回值：GraphVis 实例
  • 描述：清空图的所有边，并同步清理画布上对应的边。

渲染 ​

draw ​

  • 参数：无
  • 返回值：无
  • 描述：重新绘制所有节点及边。图形形状、样式变化时会执行。

update ​

  • 参数：无
  • 返回值：无
  • 描述：更新节点及边。节点位置信息发生变化（如布局过程中）时会执行。

数据读写 ​

getData ​

  • 参数：无
  • 返回值：GraphAttributes
  • 描述：获取原始数据。

setData ​

  • 参数：GraphAttributes | (prev: GraphAttributes) => GraphAttributes
  • 返回值：无
  • 描述：替换图的数据源。

布局 ​

getLayout ​

  • 参数：无
  • 返回值：BaseLayout
  • 描述：获取当前图的布局实例。

setLayoutOptions ​

  • 参数：LayoutOptions
  • 返回值：无
  • 描述：为当前图切换布局类型。

stopLayout ​

  • 参数：无
  • 返回值：无
  • 描述：暂停当前图的布局。

restartLayout ​

  • 参数：无
  • 返回值：无
  • 描述：重启当前布局。

节点操作 ​

addNode ​

  • 参数：NodeAttributes
  • 返回值：nodeId | undefined
  • 描述：入参为节点数据，添加一个节点。

getNode ​

  • 参数：id: string
  • 返回值：BaseNode
  • 描述：入参为节点 ID，获取节点实例。

dropNode ​

  • 参数：id: string
  • 返回值：graph 实例
  • 描述：入参为节点 ID，删除图的某一个节点。

nodes ​

  • 参数：无
  • 返回值：BaseNode[]
  • 描述：获取图的所有节点实例。

forEachNode ​

  • 参数：(node: BaseNode, attr: EdgeAttributes) => void
  • 返回值：graph 实例
  • 描述：循环节点实例。

neighbors ​

  • 参数：id: string
  • 返回值：BaseNode[]
  • 描述：入参为节点 ID，获取节点的相邻节点。

nonNeighbors ​

  • 参数：id: string
  • 返回值：BaseNode[]
  • 描述：入参为节点 ID，获取节点的非相邻点。

边操作 ​

addEdge ​

  • 参数：EdgeAttributes
  • 返回值：edgeId | undefined
  • 描述：入参为边数据，为图添加一条边。

getEdge ​

  • 参数：id: string
  • 返回值：BaseEdge
  • 描述：入参为边 ID，获取边实例。

dropEdge ​

  • 参数：id: string
  • 返回值：无
  • 描述：入参为边 ID，删除图的一条边。

edges ​

  • 参数：无
  • 返回值：BaseEdge[]
  • 描述：获取图的所有边实例。

forEachEdge ​

  • 参数：(edge: BaseEdge, attr: EdgeAttributes) => void
  • 返回值：graph 实例
  • 描述：循环边实例。

relatedEdges ​

  • 参数：id: string
  • 返回值：BaseEdge[]
  • 描述：入参为节点 ID，获取与节点相连的边。

unrelatedEdges ​

  • 参数：id: string
  • 返回值：BaseEdge[]
  • 描述：入参为节点 ID，获取与节点不相连的边。

视图与坐标 ​

getCenter ​

  • 参数：无
  • 返回值：{ x: number; y: number }
  • 描述：获取当前图的中心坐标。

global2LocalPoint ​

  • 参数：x: number, y: number
  • 返回值：{ x: number; y: number }
  • 描述：入参为全局的 x、y 坐标值，返回本地坐标。

local2GlobalPoint ​

  • 参数：x: number, y: number
  • 返回值：{ x: number; y: number }
  • 描述：入参为本地 x、y 坐标值，返回全局坐标。

translateTo ​

  • 参数：x: number, y: number
  • 返回值：无
  • 描述：将图变换平移至 x、y 坐标点。

translateBy ​

  • 参数：dx: number, dy: number
  • 返回值：无
  • 描述：将当前图 x 轴平移 dx 距离，y 轴平移 dy 距离。

centerAt ​

  • 参数：x: number, y: number, easing?: EasingType, duration?: number
  • 返回值：无
  • 描述：将当前图切换至以 x、y 坐标为中心点。easing 为动画类型，详见 EasingType；duration 为动画执行时间，单位 ms。

zoom ​

  • 参数：k: number, easing?: EasingType, duration?: number
  • 返回值：无
  • 描述：将图缩放 k 倍，使用 easing 动画，动画执行时间为 duration。easing 为动画类型，详见 EasingType。

zoomToFit ​

  • 参数：zoomFactor?: number = 1, easing?: EasingType, duration?: number
  • 返回值：无
  • 描述：图自适应，使整个图的节点、边都在显示区域内。zoomFactor 调整图距离显示区域的边距，默认为 1 无边距；数值越小边距越大，大于 1 时部分节点将超出显示区域。easing 为动画类型，详见 EasingType。

resetView ​

  • 参数：easing?: EasingType, duration?: number
  • 返回值：无
  • 描述：重置到初始状态，ZoomTransform 将被重置。easing 为动画类型，详见 EasingType。

交互 ​

startLinkNode ​

  • 参数：node: BaseNode, isDirected?: boolean = true
  • 返回值：无

  • 参数：无

  • 描述：结束添加边的交互操作。

事件 ​

on ​

  • 参数：event: GraphVisEvents, listener: (...args: any[]) => void
  • 返回值：无
  • 描述：监听事件。

once ​

  • 参数：event: GraphVisEvents, listener: (...args: any[]) => void
  • 返回值：无
  • 描述：监听事件一次。

off ​

  • 参数：event: GraphVisEvents, listener: (...args: any[]) => void
  • 返回值：无
  • 描述：解除某个事件监听函数的绑定。

事件 ​

通过 on、once、off 注册、监听与解绑事件。下表按触发对象分组。

各组内按使用频率与交互流程排序：点击/指针类在前，鼠标、右键、拖拽、触摸、滚轮依次在后；生命周期类事件按“创建 → 绘制 → 更新”排列，增删类事件按“前 → 后”排列。

图事件 ​

与图整体状态相关的事件。

事件回调函数描述
zoom(event: any) => void图进行缩放交互的过程中触发。
zoomstart(event: any) => void图开始缩放交互时触发一次。
zoomend(event: any) => void图缩放交互结束后触发一次。
resize(obj: { screenWidth: number; screenHeight: number; resolution: number }) => voidresizeTo 对应的 HTML 元素尺寸发生变化时触发。
clear() => void执行清空图方法 clear 时触发。
clearedges() => void执行清空图的边方法 clearEdges 时触发。
beforecreate() => void执行创建图元素方法 create 前触发。
aftercreate() => void执行创建图元素方法 create 后触发。
beforedraw() => void执行图元素绘制方法 draw 前触发。
afterdraw() => void执行图元素绘制方法 draw 后触发。
beforeupdate() => void执行图元素更新方法 update 前触发。
afterupdate() => void执行图元素更新方法 update 后触发。

ts
type NodeEventCallbackParams = {
  target: BaseNode;
  originalTarget: Container;
  originalType: string;
  event: FederatedPointerEvent;
};
