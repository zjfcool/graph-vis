# 简介

GraphVis 是一个基于 [PixiJS](https://pixijs.com/) 的图可视化库，专注于高性能的图数据渲染与交互。它支持上万节点与边的流畅绘制，适用于需要展示复杂关系网络的场景，如社交网络分析、知识图谱、拓扑结构、流程图等。

## 核心特性

- **高性能渲染**：基于 PixiJS 的 WebGL 渲染管线，轻松支撑上万节点与边的实时交互。
- **多种图类型**：支持有向图、无向图与混合图，满足不同关系表达需求。
- **丰富的节点与边**：内置圆形、椭圆、矩形、多边形、星形、文本、图片等多种节点类型，以及直线、曲线、自动边等边类型。
- **灵活的布局**：集成 `d3-force`、`random` 等布局，并支持自定义扩展。
- **完整的交互事件**：提供节点、边、Stage 的指针、鼠标、触摸、拖拽等事件监听，方便实现选中、悬停、连线等交互。
- **主题与样式**：支持动态切换主题，也可根据主题色自动生成配色方案。
- **可扩展架构**：通过 `register` 方法注册自定义节点、边、布局与主题，轻松扩展库的能力。
