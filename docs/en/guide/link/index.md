# Link Options (LinkOptions)

`LinkOptions` is used to configure the style of the dynamic link that follows the mouse cursor when performing edge editing operations on the graph. It is typically passed as the `link` property of `GraphVisOptions`.

`LinkOptions` inherits the `type`, `style`, `state`, `arrowConfig`, and `labelConfig` options from [`EdgeOptions`](/en/guide/edge/) by default. If `link` is configured separately, those configurations will be overridden.

```ts
type LinkOptions<D = any> = Omit<EdgeOptions<D>, "source" | "target" | "drawBy" | "id">;
```

> Compared with [`EdgeOptions`](/en/guide/edge/), `LinkOptions` removes four properties: `source`, `target`, `drawBy`, and `id`. This is because the dynamic link is generated by user interaction, its source and target nodes are not fixed, and its drawing method is fixed to `graphics`.

## 1. Options Quick Reference

| Property      | Type                                                               | Default | Description                                                          |
| :------------ | :----------------------------------------------------------------- | :------ | :------------------------------------------------------------------- |
| `type`        | [`AttrType`](/en/guide/types/#attrtype)&lt;string&gt;              | `auto`  | Edge type; built-in options are `auto`, `line`, `quadratic`, `cubic` |
| `state`       | [`EdgeStateOptions`](/en/guide/edge/#edgestateoptions)             | -       | Edge state style options                                             |
| `style`       | [`EdgeStyleOptions`](#linkstyleoptions)                            | -       | Edge style options                                                   |
| `arrowConfig` | [`EdgeArrowConfigOptions`](/en/guide/edge/#edgearrowconfigoptions) | -       | Edge arrow options                                                   |
| `labelConfig` | [`EdgeLabelConfigOptions`](/en/guide/edge/#edgelabelconfigoptions) | -       | Edge label options                                                   |

> For more properties, see [`EdgeOptions`](/en/guide/edge/).

## 2. Key Options

### 2.1 Edge Type (`type`)

`LinkOptions` inherits the `type` property from [`EdgeOptions`](/en/guide/edge/), used to specify the type of the dynamic link.

Built-in edge types:

- `auto`: Adaptive; automatically selects the appropriate type based on the edge's connection relationship
- `line`: Straight line
- `quadratic`: Quadratic Bezier curve
- `cubic`: Cubic Bezier curve

```js
link: {
  type: 'line',
}
```

### 2.2 Style (`style`)

Controls the stroke, halo, curve shape, etc. of the dynamic link. See [`LinkStyleOptions`](#linkstyleoptions) below for details.

```js
link: {
  style: {
    stroke: {
      width: 3,
      color: '#000',
    },
  },
}
```

### 2.3 Arrow Configuration (`arrowConfig`)

Controls the visibility, position, size, and style of the arrow on the dynamic link.

```js
link: {
  arrowConfig: {
    style: {
      visible: true,
      size: [8, 6],
    },
  },
}
```

### 2.4 Label Configuration (`labelConfig`)

Controls the text, position, and style of the dynamic link's label.

```js
link: {
  labelConfig: {
    labelText: () => 'New Link',
    style: {
      visible: true,
      fontSize: 12,
    },
  },
}
```

### 2.5 State (`state`)

You can define different states for the dynamic link. By default, it inherits the `state` options from `EdgeOptions`.

```js
link: {
  state: {
    active: { halo: true, haloSpacing: 3 },
  },
}
```

## 3. Link Style Options (LinkStyleOptions) {#linkstyleoptions}

`LinkStyleOptions` is identical to [`EdgeStyleOptions`](/en/guide/edge/#edgestyleoptions). Since the dynamic link's `drawBy` is fixed to `graphics`, only `graphics`-related properties take effect.

| Property            | Type                                                                      | Default | Description                                                                                                                    | drawBy   |
| :------------------ | :------------------------------------------------------------------------ | :------ | :----------------------------------------------------------------------------------------------------------------------------- | :------- |
| `visible`           | [`AttrType`](/en/guide/types/#attrtype)&lt;boolean&gt;                    | `false` | Whether the edge is visible or hidden                                                                                          | -        |
| `smoothness`        | [`AttrType`](/en/guide/types/#attrtype)&lt;number&gt;                     | `0.75`  | The smoothness of a curved edge; larger values are smoother                                                                    | -        |
| `quadraticAlongT`   | [`AttrType`](/en/guide/types/#attrtype)&lt;number&gt;                     | `0.5`   | The position of the quadratic Bezier control point along the edge; 0 is the start, 1 is the end, 0.5 is the middle             | -        |
| `quadraticRotation` | [`AttrType`](/en/guide/types/#attrtype)&lt;number&gt;                     | `0`     | The direction of the quadratic Bezier control point vector; positive values rotate clockwise, negative values counterclockwise | -        |
| `quadraticSpacing`  | [`AttrType`](/en/guide/types/#attrtype)&lt;number&gt;                     | `40`    | The spacing of the quadratic Bezier control point                                                                              | -        |
| `cubicAlongT`       | [`AttrType`](/en/guide/types/#attrtype)&lt;number \| [number, number]&gt; | -       | The positions of the two control points of the cubic Bezier curve along the edge                                               | -        |
| `cubicRotation`     | [`AttrType`](/en/guide/types/#attrtype)&lt;number \| [number, number]&gt; | -       | The directions of the two control point vectors of the cubic Bezier curve                                                      | -        |
| `cubicSpacing`      | [`AttrType`](/en/guide/types/#attrtype)&lt;number \| [number, number]&gt; | -       | The spacing between the two control points of the cubic Bezier curve                                                           | -        |
| `stroke`            | [`GStrokeStyle`](/en/guide/types/#gstrokestyle)                           | -       | Edge stroke style                                                                                                              | graphics |
| `halo`              | [`AttrType`](/en/guide/types/#attrtype)&lt;boolean&gt;                    | `false` | Whether the edge background is visible or hidden                                                                               | -        |
| `haloStroke`        | [`GStrokeStyle`](/en/guide/types/#gstrokestyle)                           | -       | Edge background stroke style                                                                                                   | graphics |
| `haloSpacing`       | [`AttrType`](/en/guide/types/#attrtype)&lt;number&gt;                     | `3`     | Spacing between the edge background and the edge                                                                               | -        |

## 4. Complete Example

The following example shows how to configure the style of the dynamic link:

```js
import { GraphVis } from "@zjfcool/graph-vis";

new GraphVis({
  // ... other options
  link: {
    type: "line",
    style: {
      stroke: {
        width: 3,
        color: "#000",
      },
    },
    arrowConfig: {
      style: {
        visible: true,
        size: [8, 6],
      },
    },
    labelConfig: {
      labelText: () => "New Link",
      style: {
        visible: true,
        fontSize: 12,
      },
    },
  },
});
```

## 5. Notes

1. **Inheritance**: `LinkOptions` inherits from [`EdgeOptions`](/en/guide/edge/). If a property is not configured in `link`, the corresponding configuration in `edge` is used.
2. **Non-configurable properties**: The four properties `source`, `target`, `drawBy`, and `id` cannot be configured in `LinkOptions`.
3. **Fixed drawing method**: The drawing method of the dynamic link is fixed to `graphics`, so only `graphics`-related properties take effect.
4. **Interaction trigger**: The dynamic link starts to appear after calling the `startLinkNode` method, and disappears after calling the `endLinkNode` method.
5. **Dynamic generation via functions**: Consistent with `EdgeOptions`, most properties in `LinkOptions` support passing a function, where the function parameter `d` is the raw edge data.

With the options above, you can flexibly control the appearance, arrow, label, and interaction state of the dynamic link.
