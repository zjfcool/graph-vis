布局配置项 (LayoutOptions) ​

LayoutOptions 用于配置图中节点的排列方式。它通常作为 GraphVisOptions 的 layout 属性传入。GraphVis 内置了 d3-force 与 random 两种布局类型，同时支持通过 register 注册自定义布局。

1. 配置项速查表 ​

属性类型默认值描述
typestring-布局类型，内置 d3-force、random

type 决定了其余配置项如何解析。选择 d3-force 时，其他属性遵循 D3ForceLayoutOptions；选择 random 时，其他属性遵循 RandomLayoutOptions。

2. 布局类型 (type) ​

内置布局类型：

  • d3-force：力导向布局，基于 d3-force 实现，适用于展示节点之间的连接关系与聚类结构。
  • random：随机布局，将节点随机分布在指定区域内，适合调试或作为其他布局的初始状态。

type 为字符串类型，直接指定布局名称：

js
layout: {
  type: 'd3-force',
  // 其他配置
}

也可以通过 register 注册自定义布局，然后使用对应的名称启用：

js
import { register } from "@zjfcool/graph-vis";

register("layout", "my-layout", MyLayoutClass);

new GraphVis({
  layout: {
    type: "my-layout",
    // 自定义布局的参数
  },
});

TIP

MyLayoutClass 需继承 BaseLayout（不可迭代布局）或 BaseLayoutWithInterations（可迭代布局），并实现对应的抽象方法与属性。

3. D3ForceLayoutOptions ​

当 layout.type 为 d3-force 时，支持以下配置项：

属性类型默认值描述
warmTicksnumber0预先执行布局多少次
cooldownTicksnumberInfinity执行布局多少次停止布局
cooldownTimenumber1500执行布局的持续时间，单位 ms
alphanumber1详情请参考 d3-force simulation.alpha
alphaMinnumber0.001详情请参考 d3-force simulation.alphaMin
alphaDecaynumber0.01详情请参考 d3-force simulation.alphaDecay
alphaTargetnumber0详情请参考 d3-force simulation.alphaTarget
velocityDecaynumber0.4详情请参考 d3-force simulation.velocityDecay
randomSource() => number-详情请参考 d3-force simulation.randomSource
linkD3ForceLinkOptions | false-详情请参考 d3-force link
centerD3ForceCenterOptions | false-详情请参考 d3-force center
collideD3ForceCollideOptions | false-详情请参考 d3-force collide
manyBodyD3ForceManyBodyOptions | false-详情请参考 d3-force many-body
xD3ForceXOptions | false-详情请参考 d3-force position.forceX
yD3ForceYOptions | false-详情请参考 d3-force position.forceY
radialD3ForceRadialOptions | false-详情请参考 d3-force position.forceRadial

TIP

将 link、center、collide、manyBody、x、y、radial 等属性设为 false 可以禁用对应的力，从而自定义布局的行为。

4. RandomLayoutOptions ​

当 layout.type 为 random 时，支持以下配置项：

属性类型默认值描述
widthnumber500随机布局的宽度
heightnumber500随机布局的高度
center[number, number][0, 0]中心点，表示以哪个中心进行随机分布

5. 完整示例 ​

5.1 d3-force 布局 ​

js
import { GraphVis } from "@zjfcool/graph-vis";

new GraphVis({
  // ... 其他配置
  layout: {
    type: "d3-force",
    warmTicks: 0,
    cooldownTicks: Infinity,
    cooldownTime: 1500,
    collide: {
      radius: 20,
      strength: 0.1,
    },
    link: {
      id: (d) => d.id,
      distance: 90,
      strength: 0.2,
    },
    manyBody: {
      strength: -20,
    },
    alphaDecay: 0.01,
  },
});

5.2 random 布局 ​

js
import { GraphVis } from "@zjfcool/graph-vis";

new GraphVis({
  // ... 其他配置
  layout: {
    type: "random",
    width: 800,
    height: 600,
    center: [400, 300],
  },
});

5.3 自定义布局 ​

js
import { GraphVis, register, BaseLayout, BaseLayoutWithInterations } from "@zjfcool/graph-vis";

// 不可迭代布局：继承 BaseLayout
class MyStaticLayout extends BaseLayout {
  // 实现抽象方法与属性
}

// 可迭代布局：继承 BaseLayoutWithInterations
class MyIterativeLayout extends BaseLayoutWithInterations {
  // 实现抽象方法与属性
}

register("layout", "my-static-layout", MyStaticLayout);
register("layout", "my-iterative-layout", MyIterativeLayout);

new GraphVis({
  // ... 其他配置
  layout: {
    type: "my-static-layout",
    // 自定义布局的参数
  },
});

6. 注意事项 ​

  1. 布局类型必填：layout.type 为必填项，未指定时不会启动任何布局。
  2. 属性兼容：不同布局类型的配置项不同，例如 d3-force 布局的 link、collide 等属性在 random 布局中不会生效。
  3. 迭代次数：d3-force 是可迭代布局，可以通过 cooldownTicks 与 cooldownTime 控制迭代的次数和持续时间。
  4. 动态切换：初始化后，可以通过 graph.setLayoutOptions() 动态切换布局类型与配置。
  5. 布局控制：可以通过 graph.stopLayout() 暂停布局，通过 graph.restartLayout() 重启布局。
  6. 自定义布局：通过 register('layout', 'your-layout', YourLayoutClass) 注册自定义布局，然后使用 layout.type: 'your-layout' 启用。YourLayoutClass 需继承 BaseLayout（不可迭代布局）或 BaseLayoutWithInterations（可迭代布局），并实现对应的抽象方法与属性。

通过以上配置，你可以灵活地控制图中节点的排列方式，从而更好地展示数据的结构与关系。
