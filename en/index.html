GraphVisA high-performance graph visualization library based on PixiJS

Smooth rendering for tens of thousands of nodes and edges

Quick Start
View Examples
  • ⚡

    Blazing Performance

    Powered by PixiJS rendering, it effortlessly handles smooth interactions with tens of thousands of nodes and edges.

  • 🎨

    Data-Driven

    Style attributes can be dynamically generated via functions, letting visuals respond to data in real time without manual redraws.

  • 🧩

    Flexible & Extensible

    Nodes, edges, layouts, and themes are all customizable and extensible to meet a wide range of scenarios.

  • 🖱️

    Rich Interactions

    Built-in zoom, pan, drag, link creation, and a complete event system — ready to use out of the box.

  • 📐

    Multiple Layouts

    Includes d3-force and random layouts, with support for custom layouts and dynamic switching on demand.

  • 🔷

    Diverse Node Types

    Built-in node types including circle, rectangle, polygon, star, image, and text.
